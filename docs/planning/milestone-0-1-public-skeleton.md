# Milestone 0.1 — Public Skeleton

## Goal

Turn the AI Engineering Almanac from an idea into a public, understandable, versioned knowledge project.

This milestone is not about having hundreds of perfect entries. It is about making the structure strong enough that hundreds of entries can be added cleanly later.

## Done means

- [ ] README explains what the project is.
- [ ] Project Direction exists.
- [ ] Roadmap exists.
- [ ] Source Strategy exists.
- [ ] Status Pipeline exists.
- [ ] First 15 canonical-entry skeletons exist.
- [ ] Prompt Finder plan exists.
- [ ] Issue templates exist.
- [ ] Pull request checklist exists.
- [ ] GitHub Pages can publish the site.
- [ ] License decision is made or explicitly marked as pending.

## First 15 entry skeletons

1. Prompt Macro
2. Workflow Phrase
3. Backend-Ready Frontend Spec
4. Field-to-Backend Mapping
5. Frontend-Backend Contract Engineering
6. Frontend-Backend Handoff Packet
7. Session-to-Wiki Compiler
8. Durable Knowledge Object
9. No-Loss Distillation
10. Extract, Don’t Summarize
11. Mock Data Must Match Final API
12. Define Done
13. Source Tiering
14. Canonical Entry
15. Docs-as-Database

## Why only 15 first?

A focused first set helps prove:

- the page template works;
- the frontmatter works;
- the navigation works;
- the source strategy works;
- the status pipeline works;
- the project has a clear personality.

After that, the project can scale into hundreds of terms.

## Public launch checklist

### Repo

- [ ] `README.md` has project overview and links.
- [ ] `PROJECT_DIRECTION.md` exists.
- [ ] `ROADMAP.md` has phases.
- [ ] `CONTRIBUTING.md` explains how to add terms/prompts.
- [ ] `.github/pull_request_template.md` exists.

### Docs

- [ ] `docs/project-direction.md` exists.
- [ ] `docs/source-strategy.md` exists.
- [ ] `docs/planning/status-pipeline.md` exists.
- [ ] `docs/ai-almanac-assistant/prompt-finder.md` exists.
- [ ] `mkdocs.yml` includes the new pages.

### Intake

- [ ] Term request issue template exists.
- [ ] Prompt macro request issue template exists.
- [ ] Source/correction request issue template exists.
- [ ] Feature request issue template exists.

### Future AI feature

- [ ] `data/prompt_macros.yml` exists.
- [ ] First 10 prompt macros are indexed.
- [ ] Prompt Finder issue exists.

## Milestone exit criteria

The project is ready for collaborators when a new person can land on the repo and understand:

- what this is;
- why it exists;
- what to add;
- how to add it;
- how quality is judged;
- what the next build target is.
